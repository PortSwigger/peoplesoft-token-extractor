Analyzes Oracle PeopleSoft single sign-on tokens (PS_TOKEN) captured in requests, decoding the token data and supporting offline password recovery and token forgery for authorized testing of PeopleSoft SSO trust relationships.

Features

  • Decodes a captured PS_TOKEN and displays its underlying fields, making the single sign-on exchange between PeopleSoft nodes inspectable.
  • Exports the token hash in Hashcat format for offline brute-force or dictionary attacks against the local node password.
  • Builds a new, validly signed PS_TOKEN for a chosen user once the local node password is known, letting testers demonstrate impersonation across trusted nodes.

Usage

  1. Capture a request containing a PS_TOKEN cookie or parameter.
  2. Send it to the extension's token tab to decode and inspect the token fields.
  3. Export the Hashcat hash and attempt to recover the local node password.
  4. With the recovered password, generate a new PS_TOKEN for a target user to test SSO trust between nodes.
